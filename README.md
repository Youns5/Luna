# Le premier vol de Luna

Une petite histoire interactive en 3D inspirée d'un conte lumineux, avec une forêt sombre, une luciole qui découvre sa lumière et un voyage visuel guidé par le défilement.

## Aperçu

Ce projet est une page web unique créée en HTML, CSS et JavaScript, avec un rendu 3D réalisé via Three.js chargé depuis un CDN.

L'expérience suit une narration visuelle :
- une forêt nocturne animée,
- une scène avec un personnage lunaire en mouvement,
- une luminosité progressive qui éclaire de plus en plus la forêt,
- des cartes de texte qui apparaissent au fil du défilement.

## Fichiers principaux

- `luna_3d.html` : page principale contenant le HTML, le CSS et le script 3D.
- `README.md` : documentation du projet.

## Comment l'ouvrir

1. Ouvre le fichier `luna_3d.html` dans un navigateur.
2. Fais défiler la page pour voir l'histoire se dérouler.
3. La scène 3D et les effets lumineux se mettent automatiquement en place.

## Prérequis

Aucun installation compliquée n'est nécessaire :
- un navigateur moderne,
- une connexion Internet pour charger Three.js depuis le CDN.

## Fonctionnalités

- arrière-plan 3D avec forêt, étoiles et lumière douce,
- animation du mouvement de caméra,
- effet bloom lumineux pour intensifier les éclats,
- progression visuelle correspondant à l'histoire,
- bouton "Recommencer" pour revenir au début.

## Personnalisation possible

Tu peux modifier directement dans `luna_3d.html` :
- les textes de narration,
- les couleurs du décor,
- l'intensité du bloom,
- les animations de caméra,
- les formes et couleurs des éléments 3D.

## Auteur

Projet créé pour une histoire visuelle simple, immersive et lumineuse.
